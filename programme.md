## Shape of the week

TYPES 2027 runs from Monday 7 to Friday 11 June 2027. As in previous editions,
the programme consists of invited lectures and contributed talks, with sessions
running through the week and a social programme in the middle of it.

| Day | | |
| --- | --- | --- |
| Monday 7 June | Registration, opening, invited lecture, contributed talks | |
| Tuesday 8 June | Invited lecture, contributed talks | |
| Wednesday 9 June | Contributed talks, excursion and social event | |
| Thursday 10 June | Invited lecture, contributed talks, conference dinner | |
| Friday 11 June | Contributed talks, closing | |
